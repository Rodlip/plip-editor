A lightweight native property list editor for **Apple Silicon · macOS 13+**.

### Download

- **Plip-arm64.pkg** — the macOS installer; installs Plip in Applications.
- **Plip-arm64.zip** — portable app; unzip and drag Plip into Applications.
- **SHA256SUMS.txt** — SHA-256 checksums for both downloads.

### Included

- Native tree editor for XML and binary property lists.
- All standard plist value types, validation, undo/redo, and search.
- File/Edit menus, Open/Save dialogs, multiple documents, and Finder Open With support.
- A custom app icon with native and Retina representations.

### Signing

This release is ad-hoc signed and is **not Apple-notarized**. On first launch, macOS may require approval in System Settings → Privacy & Security → Open Anyway. No accounts, telemetry, or network services are used by the app.
